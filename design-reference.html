The accent rule

Lime is never paired with white text — contrast fails. It carries ink only. On the deep-green hero, text uses on-brand at 100% / 72% / 45% opacity rather than the grey ink ramp.

Why family-swapping matters

React Native resolves a font by family name only, so font-bold swaps the face to InterTight_700Bold rather than leaning on font-weight. A weight utility with no matching loaded face silently renders as the system font.

03

Shape & depth

Two radii do almost all the work. Separation comes from elevation and canvas contrast, not borders.

TokenValueApplied to

Opacity scale.04 .06 .08 .12 .14 .18Sub-5% tints for subtle fills
No dark theme

Tokens are literal hex, deliberately not CSS variables — NativeWind cannot statically evaluate a var() holding an RGB triple inside rgb(), and every surface would render transparent. Adding dark mode means a dark: variant per token, not reviving a variable layer.

06

Rules that hold the system together

Constraints worth knowing before extending the design.

RuleWhy
One hero per screenThe deep-green gradient card is the focal point. Two competing heroes flattens hierarchy.
Lime = action onlyNever decorative. A lime surface should always be tappable.
Brand green ≠ optimal greenSeparate ramps so “our brand” and “healthy value” never read alike.
Skeletons hold layoutLoading states match the final geometry so nothing reflows on arrival.
Empty states explain“Building your baseline” beats an error. No red for an unconfigured state.
Never render 0 / 0The fuel strip only appears once targets exist — an empty ratio is worse than no strip.
Units are faint, values are inkThe number is the content; the unit is a label.
Destructive actions lastErase-data sits at the bottom of Settings, behind a confirm.
Fidelity caveat

Screens are hand-built HTML approximations for design discussion — they are not generated from the React Native tree, so spacing may drift by a pixel or two. Tokens in sections 01–03 are copied verbatim from tailwind.config.js and src/theme/colors.ts and are exact. Sample content shows the demo persona, not real user data.
